# Выполненные проверки

- `bash scripts/test-core.sh`: 10 проверок — цена, нечисловые данные, конкурентное принятие, перезапуск репозитория, защита адресов, порядок статусов, ограничение удаления активного заказа, чат, отзыв, удаление данных.
- `npm test`: 6 тестов серверного домена — тариф, разделение публичных/личных полей, входные границы, принятие, статусы/отмена, доступ к контактам.
- `npm run test:rules`: 8 интеграционных тестов Firebase Emulator Suite — доступ анонимного пользователя, запрос ленты перевозчика, личные данные, запрет клиентских изменений, профиль, Storage, tombstone удалённого аккаунта и callable-транзакции против эмулятора.
- Парсинг всех Swift-исходников `swiftc -frontend -parse`; сборка ядра `swift build`; проверка Node-синтаксиса и plist / Xcode project через plutil.

Эмуляторный тест вызывает `.run()` серверных обработчиков напрямую: проверяет доменную авторизацию, квоты, настоящие Firestore-транзакции и очистку данных, но не HTTP-транспорт, реальный App Check, APNs/FCM и развёртывание функций. Их нужно проверить после настройки Firebase.

При первоначальной реализации был доступен только CLT. После установки и первого запуска Xcode 26.6 прошли 2 XCTest-теста. Полноценная unsigned iOS simulator build со SwiftUI и Firebase успешно выполнена в GitHub Actions. UI-тесты, запуск на физическом устройстве, APNs/FCM и TestFlight ещё не проверены.

Для транзитивных зависимостей закреплён `uuid@11.1.1`: используемый вызов UUID v4 совместим с CommonJS и не использует изменённые буферные API. Обработчики повторно проверены после обновления.

Финальный `npm audit --omit=dev --prefix backend/functions`: 0 уязвимостей. Все 8 эмуляторных тестов повторно прошли после обновления зависимостей. Всего выполнено 24 функциональные проверки (10 Swift + 6 доменных + 8 интеграционных).

При первом запуске CI обнаружена несовместимость адресного npm override с чистой установкой npm 10 на Node 22. Override заменён общим для uuid; `npm@10.9.4 ci` и 8 эмуляторных тестов повторно прошли. Firebase iOS SDK и остальные Swift-пакеты зафиксированы в Package.resolved.

При первоначальной локальной проверке отсутствовал iOS 26.5 platform. На 10 октября 2026 года платформа установлена: `xcodebuild` успешно собрал приложение для iPhone 17 Pro (iOS 26.5 Simulator) с `CODE_SIGNING_ALLOWED=NO`. Для Debug добавлен `ONLY_ACTIVE_ARCH=YES`, чтобы приложение и Firebase-пакеты собирались для одной активной архитектуры; Release сохраняет сборку всех поддерживаемых архитектур.

Исправление входа в демо (10 октября 2026): хранилище открывается при выборе роли, неудачная попытка допускает повторное открытие; режим и профиль меняются только после успешного сохранения. Путь Application Support определяется без создания каталога средствами поиска Foundation, вложенные каталоги создаёт LocalRepository. В диагностике открытия выводятся только домен и код ошибки без путей и содержимого данных. Локальная simulator build, 10 smoke-проверок и 2 XCTest-теста прошли. В iPhone 17 Pro Simulator вручную проверены вход отправителя и переключение на перевозчика и обратно; локальный JSON создан. Точная исходная системная ошибка первого запуска неизвестна: прежний код не сохранял её диагностику. Существующие файлы демо не удалялись.

Демосборка на физическом устройстве (10 октября 2026): добавлены конфигурация Demo и схема JolParcelDemo с отдельным Bundle ID и пустыми entitlements для бесплатной Personal Team. Первый запуск был отклонён iOS проверкой подписи/доверия к профилю; пользователю предложено явно доверить разработчика на телефоне. Подтверждения работы интерфейса на физическом iPhone пока нет.
