# Выполненные проверки

- `bash scripts/test-core.sh`: 10 проверок — цена, нечисловые данные, конкурентное принятие, перезапуск репозитория, защита адресов, порядок статусов, ограничение удаления активного заказа, чат, отзыв, удаление данных.
- `npm test`: 6 тестов серверного домена — тариф, разделение публичных/личных полей, входные границы, принятие, статусы/отмена, доступ к контактам.
- `npm run test:rules`: 8 интеграционных тестов Firebase Emulator Suite — доступ анонимного пользователя, запрос ленты перевозчика, личные данные, запрет клиентских изменений, профиль, Storage, tombstone удалённого аккаунта и callable-транзакции против эмулятора.
- Парсинг всех Swift-исходников `swiftc -frontend -parse`; сборка ядра `swift build`; проверка Node-синтаксиса и plist / Xcode project через plutil.

Эмуляторный тест вызывает `.run()` серверных обработчиков напрямую: проверяет доменную авторизацию, квоты, настоящие Firestore-транзакции и очистку данных, но не HTTP-транспорт, реальный App Check, APNs/FCM и развёртывание функций. Их нужно проверить после настройки Firebase.

Полная сборка iOS, SwiftUI/Firebase typecheck, UI-тесты, Xcode XCTest и TestFlight здесь не выполнены из-за недоступности настроенного Xcode: сначала был только CLT, затем Xcode потребовал принятия лицензии. Это ограничение среды, а не успешная верификация приложения.

Для транзитивной зависимости `gaxios@6.7.1` закреплён `uuid@11.1.1`: используемый вызов UUID v4 совместим с CommonJS и не использует изменённые буферные API. Обработчики повторно проверены после обновления.

Финальный `npm audit --omit=dev --prefix backend/functions`: 0 уязвимостей. Все 8 эмуляторных тестов повторно прошли после обновления зависимостей. Всего выполнено 24 функциональные проверки (10 Swift + 6 доменных + 8 интеграционных).
