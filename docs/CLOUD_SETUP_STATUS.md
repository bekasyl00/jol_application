# JolParcel — состояние облачного подключения

Проверено 14 октября 2026 года.

## Выполнено

- Firebase CLI авторизован пользователем на этом Mac.
- Создан Firebase-проект `jolparcel-kz-2026` (JolParcel).
- Зарегистрировано iOS-приложение с Bundle ID `kz.jol.parcel`.
- Конфигурация `GoogleService-Info.plist` скачана только в игнорируемый локальный файл; callback-схема настроена в `LocalSigning.xcconfig`.
- Firestore `(default)` создан CLI при deploy правил, фактический регион — `nam5`. Включена защита базы от удаления. Это база для разработки; расположение выбранной базы не меняется при переносе Functions.
- Закрытые правила Firestore успешно опубликованы. Пользовательских данных в облако не загружали.
- Проверены сборка Debug с локальным конфигом и одинаковая генерация проекта с конфигом/без него. Скрипт сборки исключает конфиг из Demo и допускает его отсутствие в CI.
- В симуляторе открывается настоящий интерфейс телефонного входа; демоданные остаются отдельными.

## Что ещё требуется для онлайн-режима

1. Владелец подключает Blaze и платёжный аккаунт. Попытка deploy Functions остановлена Firebase: для Artifact Registry требуется Blaze.
2. Создать Storage bucket; попытка deploy Storage сообщает, что bucket не настроен.
3. Включить Phone provider, настроить SMS-регионы и тестовые номера, App Check (debug provider только для разработки), APNs/подпись для основной схемы. Не отключать проверку App Check на Functions.
4. Развернуть Functions, Storage rules, индексы и TTL. Для выдачи custom tokens проверить IAM signBlob у service account Functions; не публиковать ключи в Git.
5. Пройти регистрацию, вход, reset, предложение нескольких заказов и GPS на двух реальных устройствах, включая потерю сети, отзыв разрешения и фон.
6. Подключить GitHub deployment отдельными учётными данными/WIF. Сейчас CI проверяет код, автоматический cloud deploy отключён.

Основная схема использует облачный Firebase. `JolParcelDemo` с бесплатной Personal Team хранит демоданные только на устройстве и намеренно не отправляет SMS/GPS.

Для бесплатной разработки добавлена отдельная схема **JolParcelLocal**: сервер Firebase Emulator Suite на Mac, вымышленные SMS-коды, общий каталог и данные в локальной сети. Сборка подписана Personal Team, установлена и запущена на физическом iPhone 13; пользователь подтвердил сообщение **«Сервер доступен»**. Это не облачный deploy. Инструкция: [локальная разработка](LOCAL_DEVELOPMENT.md).

Покрытие автомобильных маршрутов Apple требует испытания в нужных городах. Если MKDirections не возвращает путь, приложение сохраняет подтверждённые точки и показывает отсутствие расчёта, не выдаёт прямое расстояние за дорожное.
