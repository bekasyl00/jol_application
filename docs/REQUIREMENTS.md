# Соответствие ТЗ и решения MVP

| Требование | Реализация / границы |
|---|---|
| iOS SwiftUI + MVVM | SwiftUI Views → @MainActor @Observable AppStore → сервисы Firebase / actor LocalRepository. AppStore служит общим ViewModel; при расширении разделить по сценариям. |
| Профиль отправителя/перевозчика | Email/password, имя, телефон, автомобиль и грузоподъёмность. Контакты не проверены SMS, документы не проверены. |
| Заказ | Города из списка 16 городов, адреса, получатель, дата, описание, вес/объём, фото, комментарий. |
| Простые размеры | Пакет 1 кг / 0.005 м³; сумка 5 / 0.025; коробка 10 / 0.06; чемодан 23 / 0.12. Параметры редактируются. |
| Цена | MapKit дорожное расстояние, формула и ручная итоговая цена. Сервер проверяет границы, но не запрашивает свой маршрут. Рекомендация не используется для списания денег. |
| Статусы | Ожидает → принят → едет к отправителю → забрал → доставил; отмена с причиной до забора. |
| Подбор по пути | Фильтры городов и даты, свои доставки. Расчёт радиуса вокруг пути и отдельная публикация поездки отложены. |
| Один перевозчик | Серверная транзакция и тест двух одновременных принятий. |
| Чат и звонок | Сообщения по заказу, обновление каждые 5 с, tel: для контактов. Участники принятого заказа получают контакты через защищённую функцию. |
| Push | FCM токены и серверные триггеры статуса/сообщения. Требуются реальные APNs/Firebase и проверка устройства. Рассылка всем водителям о новых заказах не включена. |
| История / доход / отзыв | Все собственные заказы, суммы доставленных заказов, один отзыв отправителя. Комиссия 0%. |
| Платежи | Наличные / перевод по договорённости. Нет платёжного провайдера и гарантированного получения денег. |
| Карта / геолокация | MapKit геокодит города и считает автопуть. Нет GPS-слежения, автозаполнения улиц или выбора точки на интерактивной карте. |
| Поддержка | Конфигурируемая HTTPS-ссылка в профиле; адрес оператором не задан. Отдельного чата поддержки нет. |
| Языки | Русский; казахский словарь и переключение языка — последующая задача. |
| Удаление аккаунта | Есть UI, повторная аутентификация и серверная очистка. Активные доставки сначала нужно завершить/отменить. |
| App Store | Проект, иконка, entitlements, исходный Privacy Manifest и инструкция. Сборка/публикация не выполнялись. |

В исходном описании нет первичных ссылок на долю inDrive, численность Reis.kz и размер рынка. Эти данные не верифицированы и не должны попадать в публичный маркетинг без источников. Наличие/отсутствие конкурентных функций также требует отдельного исследования.
